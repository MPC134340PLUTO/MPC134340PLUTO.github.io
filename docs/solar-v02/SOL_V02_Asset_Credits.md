- MattWalkden — Free Lunar Battle Pack，https://mattwalkden.itch.io/lunar-battle-pack 。CC0，https://creativecommons.org/publicdomain/zero/1.0/ 。上传原包 README 和 License 已核对；使用 Surface_Layer1–4、Star_Tiles，调色、平铺、拼接和整数倍放大。作者页面声明非AI。附原始许可证。
- kayillustrations — Parallax Terrestrial Planet，https://kayillustrations.itch.io/parallax-terrestrial-planet 。CC BY 4.0，https://creativecommons.org/licenses/by/4.0/ 。上传 ParallaxScifi.zip 与官方文件名吻合。使用0、2、3、5号图层，调色、平铺、裁切、最近邻2倍放大；排除虚构天体和水面图层。作者页面声明非AI。火星通用地貌艺术示意，非真实地点复原。
- Quantiset — Mars Background Pixel Art，https://opengameart.org/content/mars-background-pixel-art 。上传四张图均可读；原发布页被访问限制。衍生作品作者明确称原作CC0：https://opengameart.org/content/rocky-desert-landscape-layered-looping ，但未能直接核验原发布页。原图含假想水域和设施，未放入本补丁，无需重新下载。
- Baldur / Foozle — Void Environment Pack，CC0，https://foozlecc.itch.io/void-environment-pack 。沿用RC1三层星场。
